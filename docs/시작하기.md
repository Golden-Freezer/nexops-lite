## AI가 하는 순서 (Codex·Claude 공통)

대표님은 개발자가 아닙니다. 한 단계씩, 쉬운 한국어로, **대표님이 누를 버튼 이름**만 정확히 알려 주세요.
명령은 Windows PowerShell 기준입니다. 이미 된 단계는 확인만 하고 건너뜁니다.

### 지킬 것
- 비밀번호·인증 코드·키를 대신 입력하거나 화면에 다시 출력하지 않습니다. 로그인은 대표님이 브라우저에서 합니다.
- `npm`·`vercel`은 `npm.cmd`·`vercel.cmd`로 실행합니다(PowerShell 실행 정책 때문에 `.ps1`이 막혀 있을 수 있음).
- 설치 뒤 새 프로그램이 안 잡히면 이 창의 PATH를 다시 읽습니다.
  ```
  $env:Path = [Environment]::GetEnvironmentVariable('Path','Machine') + ';' + [Environment]::GetEnvironmentVariable('Path','User')
  ```
- 설치·로그인·사용자 폴더(`%APPDATA%\npm`, `winget`) 확인 명령은 Codex 보호 모드(sandbox) 안에서 "인식되지 않습니다", "액세스할 수 없습니다", "Access is denied", "Could not find home directory"로 실패할 수 있습니다. 이것을 '설치 안 됨'으로 단정하지 말고, 보호 모드 밖 실행 허락을 요청한 뒤 다시 확인합니다. 대표님께: "Codex가 실행해도 되는지 물으면 내용을 보고 **Yes**를 눌러 주세요."
- 막히면 오류 문장을 그대로 보여 주고, 대표님이 할 일 한 가지만 말합니다.

### 1. 지금 상태 확인
```
node -v; git --version; vercel.cmd --version; winget --version
```
없는 것만 아래에서 설치합니다. `winget`이 없으면 Node.js는 https://nodejs.org (LTS, Windows 설치 프로그램 .msi), Git은 https://git-scm.com/install/windows 를 대표님께 열어 드리고 'Next만 계속 누르기'로 안내합니다.

### 2. Node.js LTS 설치
```
winget install -e --id OpenJS.NodeJS.LTS --source winget --accept-package-agreements --accept-source-agreements
```
대표님께: "화면에 '이 앱이 디바이스를 변경하도록 허용하시겠어요?'가 뜨면 **예**를 눌러 주세요."
끝나면 PATH를 다시 읽고 `node -v`로 확인합니다.

### 3. Git 설치
```
winget install -e --id Git.Git --source winget --accept-package-agreements --accept-source-agreements
```
같은 '예' 안내. 끝나면 PATH를 다시 읽고 `git --version`으로 확인합니다.

### 4. PowerShell에서 npm 명령 허용 (대표님 계정만)
`Get-ExecutionPolicy -Scope CurrentUser`가 `Undefined`이고 `Get-ExecutionPolicy`가 `Restricted`이면 아래를 실행합니다(Microsoft 공식 방법, 관리자 권한 필요 없음). 내일 대표님이 직접 `npm run dev`를 쳐야 해서 필요합니다.
```
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser -Force
```
'그룹 정책'으로 막혀 있다고 나오면 바꾸지 말고, 내일 `npm.cmd run dev`로 치면 된다고 알려 드립니다.

### 5. Vercel 도구 설치·로그인
```
npm.cmd install -g vercel
vercel.cmd whoami
```
`whoami`에 이름이 안 나오면 `vercel.cmd login` 을 실행합니다. 대표님께: "열린 브라우저에서 **Continue with GitHub** → 승인 버튼을 눌러 주세요." 브라우저가 안 열리고 주소가 나오면 그 주소를 대표님께 보여 드립니다. 끝나면 `vercel.cmd whoami`로 이름을 확인합니다.

### 6. 레포 복사 (오늘 밤 12시 전까지만 됨)
아래 주소를 엽니다. 템플릿·이름·비공개가 미리 채워진 GitHub 화면이 열립니다.
```
Start-Process "https://github.com/new?template_owner=Golden-Freezer&template_name=nexops-lite&name=nexops-lite&visibility=private"
```
대표님께: "GitHub에 로그인돼 있지 않으면 로그인하고, 화면에 **Private**이 선택돼 있는지 본 뒤 맨 아래 초록 **Create repository** 를 눌러 주세요. 다 되면 주소창의 `github.com/` 바로 뒤 이름(대표님 GitHub 사용자 이름)을 알려 주세요."
- 'nexops-lite가 이미 있다'고 나오면 이미 복사한 것입니다. 사용자 이름만 받습니다.
- 404가 나오면 공개 시간이 지난 것입니다. 스터디장에게 연락하라고 안내합니다.

### 7. 바탕화면으로 받기
```
git clone https://github.com/<사용자이름>/nexops-lite "$HOME\Desktop\nexops-lite"
```
처음이면 Git 로그인 창이 뜹니다. 대표님께: "**Sign in with your browser** → 브라우저에서 초록 승인 버튼을 눌러 주세요."
이미 폴더가 있으면 그 폴더에서 `git pull`만 합니다.

### 8. 부품 설치
```
cd "$HOME\Desktop\nexops-lite"; npm.cmd install
```
몇 분 걸립니다. 노란 'warn'은 괜찮습니다.
