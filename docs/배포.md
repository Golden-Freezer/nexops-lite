# 처음 배포 (스터디 당일, 약 30~40분)

대표님은 **브라우저 로그인과 '허용' 버튼만** 누르시고, 나머지는 AI(Codex 또는 Claude)가 합니다.
아래 순서는 2026-11-27 스터디장 시험 계정으로 실제로 끝까지 해 본 순서입니다.

## 0. 준비 (사전 과제)
- 가입: GitHub · Vercel · Supabase
- 설치: Node.js LTS · Git · `npm install -g @openai/codex` · `npm install -g vercel`
- 로그인: `codex`(Sign in with ChatGPT) · `vercel login`
- 내 GitHub에 nexops-lite 비공개 사본(Use this template)

## 1. AI에게 이렇게 말하기
바탕화면에서 PowerShell을 열고 `codex` 를 실행한 뒤 아래를 붙여 넣습니다.

```
내 GitHub 계정의 nexops-lite 레포를 바탕화면\nexops-lite 폴더로 받아 줘(git clone).
그 폴더의 docs\배포.md '2. AI가 하는 순서'를 처음부터 끝까지 진행해 줘.
브라우저 로그인이 필요하면 나에게 알려 주고 기다려 줘. 비밀번호와 키는 화면에 다시 보여 주지 마.
```

## 2. AI가 하는 순서
1. `npm install`
2. Supabase 로그인: `npx supabase login` → 브라우저에서 대표님이 허용
3. 조직 확인: `npx supabase orgs list` (조직이 없으면 대표님이 supabase.com에서 조직 1개 만들기, Free)
4. DB 비밀번호를 무작위로 만들고 `장부받기\DB비밀번호.txt`에만 저장(화면에 출력하지 않음)
5. 프로젝트 만들기:
   `npx supabase projects create nexops-lite --org-id <조직ID> --db-password <비밀번호> --region ap-northeast-2`
6. 1~2분 뒤 키 받기: `npx supabase projects api-keys --project-ref <ref> -o json` → `.env.local` 작성
   ```
   NEXT_PUBLIC_SUPABASE_URL=https://<ref>.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=<anon>
   SUPABASE_SERVICE_ROLE_KEY=<service_role>
   ```
7. 표 만들기: `npx supabase link --project-ref <ref> -p <비밀번호>` → `npx supabase db push` (질문에 y)
8. Vercel 연결: `vercel link --yes` (프로젝트 이름은 폴더 이름 nexops-lite)
9. Vercel 환경 변수(값은 .env.local에서 읽어 넣기, 화면 출력 금지):
   ```
   vercel env add NEXT_PUBLIC_SUPABASE_URL --environment production --type config --value "<값>" --yes
   vercel env add NEXT_PUBLIC_SUPABASE_ANON_KEY --environment production --type config --value "<값>" --yes
   vercel env add SUPABASE_SERVICE_ROLE_KEY --environment production --type secret --value "<값>" --yes
   ```
   (anon 키는 원래 브라우저에 공개되는 키라 config, service_role 키는 비밀이라 secret)
10. 배포: `vercel --prod --yes` → 끝에 나오는 `Production: https://….vercel.app` 주소를 대표님께 알려 드리기
11. 대표님이 그 주소에서 첫 가입(이메일·비밀번호 8자 이상). 첫 1명 뒤로 가입이 닫힙니다.

## 3. 상품 불러오기와 첫 장부 업데이트
1. 장부 ▶ 설정 ▶ 업로드 키 ▶ 토큰 발급 → 나온 키를 복사
2. AI에게: "장부받기 설정해 줘" → AI가 `npm run ledger`를 한 번 돌려 `장부받기\설정.txt`를 만들고, 장부 주소와 업로드 키를 적어 줍니다
3. 먼저 연습: `npm run ledger -- --시험` (가짜 원목도마 3종이 올라감, 나중에 상품 관리에서 지워도 됨)
4. 실제: "오늘 장부 업데이트해 줘" → 크롬 창이 뜨면 쿠팡 Wing에 로그인(처음 한 번, 2단계 인증) → 판매 통계(어제)·재고 현황·광고비 정산 3개를 받아 장부에 올립니다
   - 재고 현황을 올리면 Wing의 로켓그로스 상품이 상품 관리에 자동 등록됩니다(= 상품 불러오기)
5. 주력상품: 광고센터 ▶ 광고 보고서 ▶ 매출 성장 광고 보고서에서 받은 `*_pa_total_campaign_*.xlsx`를 웹 '파일 올리기'에 끌어 놓기(판매 통계를 한 번 올린 뒤에 해야 상품과 연결됩니다)

## 막혔을 때
| 증상 | 할 일 |
|---|---|
| 배포 주소가 404 | 레포에 `vercel.json`이 있는지 확인 후 `vercel --prod --yes` 다시 |
| 로그인 화면에 'Supabase 연결 값이 아직 없습니다' | 9번 환경 변수 3개 확인 후 다시 배포 |
| `supabase projects create`가 한도 오류 | 무료 조직은 프로젝트 2개까지. supabase.com에서 새 조직(Free)을 만들거나 안 쓰는 프로젝트 정리 |
| 장부받기가 '업로드 키가 맞지 않습니다' | 설정 ▶ 업로드 키에서 새로 만들어 설정.txt에 다시 적기 |
| Codex가 상세페이지 만들기에서 멈춤 | `codex login status`가 ChatGPT 로그인인지 확인 |
